# 迈宝零现金成本外部算力池

本仓库用于验证和演进“本机只负责点火、正式计算全部由外部合法零现金成本节点承担”的分布式算力体系。

## 已完成的 V0（零版）

- 本机正式计算占比为 0%。
- 4 个外部托管计算节点并行执行。
- 第 5 个外部节点统一汇总并进行确定性校验。
- 真实运行已经通过并留下永久验收记录。

## V1（第一版闭环）

V1 在 V0 基础上增加：

1. 根据任务规模自动决定分片数量；
2. 自动生成外部并行计算矩阵；
3. 主分片失败后自动检测缺失或无效结果；
4. 只对缺失分片启动外部补算；
5. 主结果与补算结果自动合并；
6. 外部汇总节点验证区间完整性、每片结果、最终总结果以及零本机正式计算约束；
7. 保存计划、修复计划和最终验收证据。

默认验收参数为 40,000,000 个计算项、每片目标 5,000,000 项、最多 16 片，因此系统会自动生成 8 个分片。验收时故意中断主分片 2；只有系统自动识别并补算该分片后最终结果仍然正确，才判定闭环通过。

## 固定边界

- 本机仅承担启动、控制和查看状态，不计入正式算力池。
- 正式计算只允许在合法、公开允许使用且本次新增现金计算成本为零的外部资源上执行。
- 当前实验只使用公开仓库中的标准托管运行器和合成数据。
- 不使用生产代码、私密数据、秘密凭据、付费云资源或大型付费运行器。
- 单一计算节点失败不能导致整体任务失败；可以补算时必须自动恢复。
